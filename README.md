# twei0571.github.io

Personal academic website of Tianlan Wei, PhD student in Geographical Sciences at the University of Maryland.
Live at <https://twei0571.github.io>.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: one self-contained page (HTML, CSS and a small theme-toggle script inline) |
| `cv.pdf` | Public CV linked from the "Download CV" button. It is a redacted copy of the private CV, not the original |
| `photo.jpg` | Headshot, 640 × 640 |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are, without a Jekyll build |

## Updating

- Edit `index.html` directly and commit to `main`; GitHub Pages republishes within a minute or two.
- Publications are grouped by year under `#publications`; put your own name in `<b>…</b>`.
- Change the "Last updated" line in the footer when content changes.
- To replace the CV, export the new PDF, remove anything that should not be public, and overwrite `cv.pdf` under the same name.
